# Community conduct

Be curious, specific, and considerate. Discuss the work without attacking the person.

- Welcome contributors with different experiences, languages and abilities.
- Explain problems with reproducible examples and constructive suggestions.
- Respect consent, privacy, copyright and other people's time.
- Do not harass, threaten, discriminate, publish private information or disrupt discussions.
- Credit original work and make limitations visible.

Maintainers may edit or remove harmful contributions and restrict participation when necessary. They should explain moderation decisions when doing so does not expose private information. Report concerns privately using the contact method on the [maintainer's profile](https://github.com/hslcrb). No response deadline is promised.
