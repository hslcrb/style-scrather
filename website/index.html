A FEW THINGS TO KNOW

시작 전에.

이 페이지의 데모와 확장 프로그램은 어떻게 다른가요?＋

데모는 위의 예제 요소만 선택하고 조정하는 작은 체험입니다. 확장 프로그램을 설치하면 지원되는 실제 웹 페이지에서 검사, 측정, 편집 도구를 사용할 수 있습니다.

편집한 내용이 원래 사이트에 저장되나요?＋

아니요. 라이브 편집은 내 브라우저의 현재 페이지에 적용됩니다. 사이트의 서버나 원본 소스는 바뀌지 않으며, 새로고침이나 앱의 재렌더링으로 변경이 사라질 수 있습니다.

모든 페이지와 요소를 검사할 수 있나요?＋

Chrome 내부 페이지와 확장 스토어 등에서는 브라우저가 주입을 제한합니다. 교차 출처 프레임, 닫힌 Shadow DOM, 캔버스 내부 그래픽이나 외부 폰트도 접근이 제한될 수 있습니다. 내보낸 코드는 원본 프로젝트를 완전히 복원하지 않으므로 직접 검토해야 합니다.

오류를 발견하거나 개선을 제안하려면요?＋

재현 방법과 사용 중인 Chrome 버전을 GitHub 이슈에 남겨 주세요. 웹사이트 데모는 외부 폰트나 분석 도구 없이 작동합니다. 확장 프로그램의 권한과 동작은 공개된 소스에서 확인할 수 있습니다.
