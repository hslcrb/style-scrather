# Look closer. Make it yours.

좋은 화면에는 이유가 있습니다. 글자의 크기, 줄 사이의 숨, 버튼의 모서리, 요소와 요소 사이의 거리. Style Scratcher는 그 이유를 관찰하고 작은 변화를 직접 시도하는 도구입니다.

## 1. 관찰에서 시작합니다

화면을 구성하는 실제 요소와 계산된 스타일을 먼저 보여줍니다. 디자이너가 발견한 미묘한 차이를 개발자가 이해할 수 있는 값으로 연결합니다. 도구의 장식보다 페이지와 선택된 요소가 우선입니다.

## 2. 변화의 범위를 분명히 합니다

라이브 편집은 현재 브라우저 페이지를 바꾸는 실험입니다. 사이트의 서버나 원본 소스 코드를 수정하지 않습니다. 페이지 새로고침, 앱의 재렌더링, 탐색으로 변경이 사라질 수 있습니다. 내보낸 코드도 실제 프로젝트의 문맥에서 검토해야 합니다.

## 3. 사용자가 시작하고 멈춥니다

검사는 요청할 때 시작합니다. 선택 상태, 잠금, 작업 성공과 실패를 숨기지 않습니다. 단축키와 포인터 조작을 함께 제공하고, 도구를 닫으면 페이지를 다시 사용할 수 있어야 합니다. 기능이 브라우저 권한이나 웹 플랫폼의 제약을 만나면 그 이유를 설명합니다.

## 4. 유리는 투명하고, 설명은 선명합니다

가벼운 유리 표면은 페이지의 맥락을 유지합니다. 읽기 어려운 투명도, 과도한 움직임, 모호한 아이콘은 줄입니다. 밝거나 어두운 사이트, 좁은 창, 키보드 탐색, 동작 줄이기 설정에서도 같은 판단을 할 수 있도록 만듭니다.

## 5. 검증할 수 있는 도구를 만듭니다

소스, 설치 방법, 알려진 제약을 함께 공개합니다. 확인한 동작과 아직 확인하지 않은 동작을 구분합니다. 디자인은 시각 효과뿐 아니라 오류 상태, 성능 비용, 접근성, 복구 방법까지 포함합니다.

## 지원 범위에 관한 약속

- Chrome의 일반 웹 페이지에서 요소 검사와 임시 스타일 편집을 돕습니다. 브라우저 내부 페이지, 확장 스토어 등 Chrome이 주입을 제한하는 화면에서는 사용할 수 없습니다.
- 교차 출처 프레임, 닫힌 Shadow DOM, 캔버스 내부 그래픽, 웹폰트와 외부 리소스는 접근 또는 추출이 제한될 수 있습니다.
- CSS/Tailwind/React 등의 내보내기는 원본 프로젝트를 복원하지 않습니다. 동작, 상태, 반응형 규칙, 접근성, 사용 권한을 직접 검토해야 합니다.
- 외부 에셋 요청이나 다운로드는 대상 서버의 정책과 네트워크 상태에 영향을 받습니다. 모든 사이트의 보호 장치나 브라우저 정책을 우회한다고 약속하지 않습니다.

Style Scratcher는 웹을 더 잘 보고 더 신중하게 바꾸도록 돕습니다.
