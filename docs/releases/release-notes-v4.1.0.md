# Style Scratcher v4.1.0. — Liquid Studio

**웹을 읽는 눈, 디테일을 바꾸는 손.**

v4.1.0은 필요한 순간에 켜는 웹 검사 작업대입니다. 기존 선택 프레임 로고와 Studio Crimson을 계승하고, 읽기 쉬운 리퀴드 글래스 UI, 명확한 실행 상태, 페이지 제어 복원과 검증 가능한 배포를 함께 정리했습니다.

## 설치

1. 이 릴리즈의 **`style-scratcher-4.1.0.zip`**과 checksum 파일을 받습니다.
2. ZIP의 압축을 풉니다.
3. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 일반 웹 페이지에서 확장 아이콘 또는 **Alt+S**로 시작합니다.

확장 실행에는 npm 설치나 로컬 서버가 필요하지 않습니다. GitHub가 자동으로 제공하는 Source code 아카이브와 별도로, 위 ZIP은 설치에 필요한 파일만 담은 로컬 빌드입니다.

## 달라진 경험

- Pearl·Ink·Crimson 색상과 정돈된 선택 프레임 마크, 유리 표면의 팝업·스튜디오를 적용했습니다.
- 네 개 핵심 탭과 보조 도구 메뉴로 열 개 패널을 구성했습니다. 키보드 탐색, 이동, 최소화, focus 표시, reduced motion과 320px 창 대응을 제공합니다.
- 실제 DOM을 선택하고 색·모서리·글꼴·CSS를 조정하는 한국어 소개 페이지와 확장 실습 페이지를 추가했습니다.
- 브랜드·철학·기여·보안·개인정보·아키텍처·개발·검증 문서를 정리하고 과거 릴리즈 기록을 보존했습니다.

## 오류와 병목 수정

- 페이지 로드와 팝업 상태 조회만으로 검사기를 켜지 않습니다. 명시적인 요청 때 한 번 초기화합니다.
- manifest 기준 주입, 반복 주입 가드, service worker 폰트 다운로드를 복구했습니다.
- 종료 시 줌과 CSS priority, 임시 이벤트 제어, 애니메이션 상태, 그리드·기준선·커서·탭 순서와 UI 리스너·타이머를 정리합니다.
- 오버레이 갱신을 프레임 단위로 병합하고 비활성 상태의 그리기를 멈춥니다. 스캔과 폰트 작업에 상한을 두고 업데이트 확인을 공유·캐시합니다.
- JSX 텍스트·속성·void 요소와 SVG 문자열을 안전하게 직렬화합니다. 404·네트워크·본문 오류를 다운로드 성공으로 처리하지 않습니다.
- 코드 패널의 선택 에셋 저장, 비동기 오류 안내, 글꼴 변경 뒤 측정과 탭 이동 중 진행 상태를 바로잡았습니다.
- 문자 폭 측정과 실제 폰트 글리프 지원을 구분합니다. 근거 없는 지원률과 가짜 대체 윤곽선을 제거했습니다.

## 배포와 지원 범위

저장소 소유자의 요청으로 GitHub Actions workflow는 모든 줄을 `#` 처리한 `.yml.disabled` 파일로 보관했습니다. 이번 파일은 현재 실행 환경에서 직접 검증하고 빌드했습니다. 과거 hosted runner의 계정 제한을 로컬 검사 실패나 성공으로 표시하지 않습니다.

데스크톱 Chrome/Chromium용 GitHub 배포입니다. Chrome Web Store 심사, Windows/macOS 실제 설치, Firefox/Safari와 모든 외부 사이트 조합을 검증한 것은 아닙니다. 브라우저 내부 페이지, 교차 출처 iframe, 닫힌 Shadow DOM과 외부 폰트 접근에는 제약이 있습니다. 사용자 CSS·텍스트·DOM 편집은 현재 페이지의 실험이며 전체 초기화는 새로고침을 사용합니다.

소개 페이지는 `npm run build`가 생성하는 `dist/site/`에 포함됩니다. 새 공개 호스팅은 별도로 구성해야 합니다. 원본 소스에서 `npm start`로 소개 페이지와 `/demo/`를 열 수 있습니다.
