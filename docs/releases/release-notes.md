## 🎉 Style Scratcher (스타일 스크래처) v1.0.0 정식 릴리즈

디자이너와 프론트엔드 개발자의 개발자 도구(DevTools) 노가다를 없애주는 화이트 미니멀 피그마 감성 웹 인스펙터 & 실시간 CSS 튜너의 첫 번째 공식 릴리즈입니다!

---

### ✨ 주요 핵심 기능 (Key Features)

1. **🎨 화이트 미니멀 스튜디오 디자인 (White Minimal Studio)**
   - 순백색(`#FFFFFF`)과 소프트 마이크로 보더(`#E5E7EB`)를 적용한 세련된 스튜디오 UI.
   - 단정한 `6px` ~ `8px` 스퀘어클 버튼 라디우스 규격 엄격 적용 (캡슐/완전 반원 배제).
   - Shadow DOM 캡슐화로 방문한 웹사이트와의 CSS 충돌을 완벽 차단.

2. **📐 피그마 스마트 룰러 (Figma Distance Rulers & Guides)**
   - 요소를 클릭해 고정한 뒤 다른 요소에 마우스를 올리면 피그마(Alt 키)처럼 상·하·좌·우 픽셀 간격(px) 가이드라인과 측정 뱃지가 실시간 표시.
   - 12컬럼 반응형 레이아웃 그리드 및 8px 베이스라인 타이포그래피 정렬 그리드 지원.

3. **⚡ 실시간 스타일 튜너 (Live CSS Sandbox)**
   - Border Radius: 통합 슬라이더/인풋 및 4모서리(TL, TR, BL, BR) 개별 곡률 실시간 조작.
   - 시각적 박스 모델: Margin과 Padding을 다이어그램에서 확인 및 슬라이더로 즉시 변경.
   - 컬러 & 타이포그래피: 배경색, 텍스트색, 테두리색(컬러피커/HEX)과 폰트 크기/두께/정렬 즉각 반영.
   - 원클릭 초기화 (Reset): 수정한 스타일을 1초 만에 원래 상태로 복구.

4. **🚀 스마트 코드 생성 & Tailwind 변환**
   - 인스펙트한 요소의 스타일을 분석하여 `rounded-md p-4 bg-white text-gray-900 shadow-md` 등 모던 Tailwind 유틸리티 클래스로 즉시 변환.
   - 브라우저 기본값 300개를 걸러낸 정제된 클린 CSS 및 HTML 태그 원클릭 복사.

5. **🔍 사이트 CSS 난독화 해제 (CSS De-minifier) & 컬러 팔레트**
   - 한 줄로 뭉쳐진 난독화/압축 CSS를 2-space 들여쓰기와 표준 개행으로 완벽하게 미화.
   - 스타일시트 내 클래스/속성 초고속 실시간 검색.
   - 웹사이트 전반에 사용된 모든 고유 색상 및 폰트를 빈도순으로 자동 추출하여 팔레트 제공.

### 📦 Chrome 브라우저 설치 및 사용 가이드

1. 아래 **Assets**에서 `style-scrather-v1.0.0.zip` 파일을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 원하는 폴더에 해제합니다.
3. Chrome 브라우저 주소창에 `chrome://extensions` 를 입력하고 이동합니다.
4. 우측 상단의 **'개발자 모드 (Developer mode)'** 스위치를 켭니다.
5. 좌측 상단의 **'압축해제된 확장 프로그램을 로드합니다 (Load unpacked)'** 버튼을 클릭합니다.
6. 압축을 해제한 폴더를 선택하면 즉시 등록 완료됩니다!
7. 웹 서핑 중 `Alt + S` 를 누르면 언제 어디서나 Style Scratcher 인스펙터가 활성화됩니다.
