YOUR FIRST FIVE MINUTES

작은 실험 다섯 가지

  1. 아직 검사기를 켜지 않았다면

    왼쪽 버튼을 눌러 숫자가 올라가는지 확인하세요. 페이지는 평소처럼 작동해야 합니다.

  2. 요소를 고르기

    Alt + S로 켠 뒤 제목을 클릭하세요. 선택 영역과 스타일을 확인할 수 있습니다.

  3. 한 가지씩 바꾸기

    글자 크기나 모서리 값을 바꿔보세요. 스타일 초기화로 되돌릴 수 있습니다.

  4. 색과 코드를 기록하기

    코드 탭에서 팔레트와 CSS를 확인하세요. 복사한 코드는 프로젝트에 맞게 다듬어 사용합니다.

  5. 작업을 마치기

    검사기를 끄고 버튼을 다시 눌러보세요. 전체 페이지 편집은 새로고침으로 초기화됩니다.
